# Version 0.3 plan

Version 0.3 is built in slices. Each slice is one version number, one branch and one pull request.

| Slice | Content | State |
| --- | --- | --- |
| 0.3.0 | Search and command palette; delete and trash | built (see PROGRESS.md) |
| 0.3.1 | Wikilinks and backlinks | not started |
| 0.3.2 | Tags and favorites | not started |
| 0.3.3 | Covers | not started |
| 0.3.4 | Export and page history | not started |

The order after 0.3.0 is the owner's to change. Columns are not part of 0.3: they wait for a format decision (see PROGRESS.md).

## 0.3.0 rules
- Delete is reversible: pages and folders go to a hidden `.trash` folder in the notes folder. Only Delete forever and Empty trash remove files, after a question.
- Search has no index; it reads the pages each time, with limits. An index may only ever be a cache that can be rebuilt from the files.
- The search box and the Trash box are the only new screens. The commands in the box are only ones that exist.
- Not in 0.3.0: jumping to the match inside the page, search in picture names, automatic emptying of the trash.
