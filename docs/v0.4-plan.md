# Version 0.4 plan: canvas and ink

The v1 spec describes 0.4 as "Blocks, Split and Canvas modes, pressure-sensitive drawing tools, lasso, anchored draw-over-text, PDF import". That is too much for one build, so it is built in slices, like 0.3. Each slice is one version number, one branch and one pull request. The order is the owner's to change.

| Slice | Content | State |
| --- | --- | --- |
| 0.4.0 | A Canvas mode for a page: pressure pen, eraser, colours and widths, undo and redo, pan and zoom, saved next to the page | built |
| 0.4.1 | Highlighter, shapes, sticky notes, lasso (select, move, delete), pen button mapping as a setting | built |
| 0.4.2 | Tidy-up after trying 0.4.1 on the tablet: a compact drawing toolbar with menus, and Settings, Tags and Trash as buttons like New page | built |

| 0.4.4 | Sticky notes drawn as boxes and resizable, shapes snap to a grid, the OneNote pen colours, a pinch zoom fix (owner requests) | built |

| 0.4.6 | Highlights behind ink and tidied against figures (owner request), split mode with a default view setting | built |

Choices made at the start (the owner chose "Canvas page: pen + eraser" as the first slice, 2026-11-06):
- The first slice is the drawing sheet itself, with no connection to the text of the page, because everything later (anchoring, split view, PDF) needs the sheet, the pen and the storage to work first.
- Draw over text is the hardest part and gets its own slice, so that it can be tried on a device before anything is built on it.

## Canvas and pen (0.4.0)
- A page has a "Canvas" button next to "Markdown" at the top. It switches the page to its drawing sheet and back. Opening another page leaves the canvas. The text of the page is not touched by anything drawn.
- The drawing is stored in `Name.canvas.json` next to `Name.md`, one stroke per line. Obsidian ignores it. It follows the page when the page is renamed, moved, deleted to the trash or restored. See DECISIONS.md.
- Tools: pen, eraser (removes whole strokes), move the sheet. Six pen colours (the theme's text colour and the five accent colours the text colours use, so they change with the theme) and three widths. Pressure from the pen makes the line thinner or thicker; a mouse draws the plain width.
- A pen or a mouse draws. A finger moves the sheet (one finger) or zooms it (two fingers); "Finger draws" turns that around for a device with no pen. The barrel button or the eraser end of a pen erases while held. The mouse wheel moves the sheet, Ctrl and the wheel (or a trackpad pinch) zooms, space with a mouse moves the sheet. Undo and Redo by button, Ctrl+Z and Ctrl+Shift+Z.
- Limits: 20,000 strokes, 5,000 points per stroke, 1,000,000 points in all, a 32 MiB file. At the limit the drawing says it is full and does not add more.
- A drawing that cannot be read (damaged, or from a newer version) is shown as far as possible and never changed or saved over. If the file is changed by another program while the canvas is open, saving stops and the other drawing is kept.
- Not in 0.4.0: highlighter, shapes, sticky notes, lasso, drawing over text, split mode, PDF import, exporting or printing a drawing, a drawing in the page history, erasing part of a stroke, an infinite sheet scrollbar or minimap.

## Highlighter, shapes, sticky notes, lasso (0.4.1)
- New tools next to the pen: select with a loop, highlighter, line, arrow, rectangle, ellipse, sticky note. They share the colour and width choice. A highlighter line is four times as wide as the pen line of the same width, see-through, and ignores pressure.
- A loop selects what it surrounds (items with at least half of their points inside). Drag the selection to move it; Delete, the trash button or Escape. Undo and Redo cover moves, deletes and note text.
- A sticky note is a coloured box with text, typed in a text box over the sheet. A note with no text is not added.
- The side button of a pen is a setting (Settings, "Drawing"): erase, select with a loop, or nothing.
- File format 2 holds all of this; a pen-only drawing stays format 1. See DECISIONS.md.
- Not in 0.4.1: resizing, recolouring a selection, copy and paste, free text, connectors.

## The `/canvas` block (0.4.9, planned)
Added at the owner's request (2026-11-06), after he asked whether something like `/canvas` from ScaleNote v1 was planned. The v1 spec's slash menu has "Canvas (embeds a region of the page's canvas)".
- Typing `/canvas` in the text of a page puts a block in the text that shows one region of that page's canvas, at a fixed size in the text. Drawing in the block draws on the page's canvas, inside that region, with the same tools as the Canvas mode. Opening the whole canvas shows the same drawing, so the block is a window onto it, not a separate drawing.
- It comes after drawing over text (0.4.8) because it needs the same link between the text of a page and its drawing (blocks that know about the drawing). It also needs the tools of 0.4.1.
- How the block is stored in the markdown is not decided yet. It must keep the clean-markdown rule (Obsidian shows it as something harmless, and unknown syntax is kept byte for byte). Decide at the start of 0.4.9, with the owner, before building.
- Questions to settle then: can a region be moved or resized; can there be several blocks on one page (each its own region of the same canvas); what happens to the drawing inside a region when the block is deleted (keep it on the canvas, the safe default).
- Not planned for this slice: a canvas block that holds its own separate drawing, and blocks that show another page's canvas.

## Compact toolbar and sidebar buttons (0.4.2)
Owner request (2026-11-06), after trying 0.4.1 on the tablet: the drawing area was too thin because the toolbar took three lines, drop-downs or toggles in the toolbar would help, and Settings, Tags and Trash should look and behave like New page and New folder.
- The toolbar keeps the main tools in view (select, pen, highlighter, eraser, move, note, undo, redo, delete selection). Shapes, colour, line width and the less used switches (Finger draws, Show all) are menus that open under their button. A menu button shows what is chosen now: the shape used last, the colour, the line width. A menu closes when something is chosen, on Escape, on a press anywhere else, or on pressing its button again (Finger draws is a switch, so its menu stays open to show it).
- The toolbar is one line on a wide window and two on a phone, where it used to be three.
- Settings, Tags and Trash are outlined buttons with an icon and a label on one line, like New page and New folder, and the label goes away (leaving the icon, with the label as its name) when the list is narrower than 17 rem.
