# ScaleNote 0.4.9

This is still an early test version: keep your own backup of anything you care about.

## Changed
- Fixed: on Linux, all text turned bold once a page was long enough to scroll. The 0.4.8 change did not work. The cause is the way the Linux web view draws the window, so ScaleNote now switches off its faster drawing path when it starts. Drawing is a little slower in return. If you want the faster path back, start ScaleNote from a terminal with `WEBKIT_DISABLE_DMABUF_RENDERER=0`. Windows and Android are not touched.
- Fixed: a bulleted list, a numbered list and a to-do list written one after another opened as one block of plain text. They now open as three lists you can edit. Two lists of different kinds with a blank line between them are always read as two lists.
- Fixed: a toggle with a callout inside it opened as a block of plain text with the label "Kept exactly as written". Callouts, toggles, tables and pictures can now sit inside a toggle or a callout, and open as the real thing. A toggle you do not change is never rewritten.
- Text that the editor still cannot show as a block no longer has a frame or a label. It looks like the rest of the page, wraps like the rest of the page, and is still kept exactly as you wrote it.

## Good to know
- Text that the editor cannot show as a block, such as a list with blank lines between its own items or html it does not know, is still shown as it is written, with its markdown signs visible. It is shown that way so that nothing in your pages can be changed by opening them.
- A toggle or callout inside others more than eight levels deep is shown as written.

## Known limits
- Two-finger zoom on Linux still zooms the whole window, and finger drawing on the canvas can still move the screen instead of drawing. Known, not fixed in this version.
- Drawing over text, columns and the Android in-app installer are planned for 0.4.10.
