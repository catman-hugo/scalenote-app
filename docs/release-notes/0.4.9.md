# ScaleNote 0.4.9

This is still an early test version: keep your own backup of anything you care about.

## Changed
- Fixed (for real this time): on Linux, all text turned bold once a page was long enough to scroll. The fix in 0.4.8 did not work. The cause is the way the Linux web view draws the window, so ScaleNote now switches off its faster drawing path when it starts. Drawing is a little slower in return. If you want the faster path back, start ScaleNote from a terminal with `WEBKIT_DISABLE_DMABUF_RENDERER=0`.

## Good to know
- This only changes how the window is drawn on Linux. Windows and Android are not touched, and no page, drawing or setting changes.

## Known limits
- Two-finger zoom on Linux still zooms the whole window instead of the drawing, and finger drawing on the canvas can still move the screen instead of drawing. Both are known and not fixed in this version.
- Drawing over text, columns and the Android in-app installer are planned for 0.4.10.
