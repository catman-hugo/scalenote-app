# ScaleNote 0.2.8

A small release. This is still an early test version: keep your own backup of anything you care about.

## Fixed
- The Android app now has the ScaleNote logo as its icon, on the home screen and in the list of open apps. Until now it showed the default logo of the toolkit the app is made with. The Windows and Linux versions already had the ScaleNote logo.

## Note
If the old icon is still shown after you update, restart the phone's launcher or the phone: Android keeps the old picture for a while.
