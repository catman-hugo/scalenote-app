This is still an early test version: keep your own backup of anything you care about. The home server has only been tried on one computer, not on a real server over days.

## New
- **Home server (Linux).** `scalenote-server` is the sync part of ScaleNote as a program with no window. It is a paired device that is always on, so your devices can sync with it when the others are off. It holds several vaults; each vault has its own folder, port, key and list of paired devices, and a device paired with one cannot reach another. It works on the home network and over a private network such as Tailscale by typing the address. The install guide is `docs/home-server.md` (also in the download).
- **Bigger Settings window** on a computer: about four fifths of the screen.
- **Themes as cards**, with True white and True black, and a full-screen Settings list on phones (from 0.5.4, re-released).
