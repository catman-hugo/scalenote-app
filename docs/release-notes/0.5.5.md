This is still an early test version: keep your own backup of anything you care about. The home server has only been tried on one computer, not on a real server over days.

## New
- **Home server (Linux).** `scalenote-server` is the sync part of ScaleNote as a program with no window. It is a paired device that is always on, so your devices can sync with it when the others are off. It holds several vaults; each vault has its own folder, port, key and list of paired devices, and a device paired with one cannot reach another. It works on the home network and over a private network such as Tailscale by typing the address. The install guide is `docs/home-server.md` (also in the download).
- **Bigger Settings window** on a computer: about four fifths of the screen.
- **Themes as cards**, with True white and True black, and a full-screen Settings list on phones (from 0.5.4, re-released).

- **Backups.** Settings, Files: "Make a backup" copies all your pages and files into a folder next to your notes folder, named after the time. It shows when the last backup was made. "Restore" (press twice) puts back what is missing and what you changed since; it deletes nothing, and a page that is replaced is first saved in a hidden folder inside your notes folder. Not on Android.
- **A colour per folder.** In the folder menu at the top of the page list you can give each folder a colour; it shows beside the name and in the list. **Ctrl+Shift+O** opens that menu from the keyboard.
- **Security cards.** Settings, Sync now has three short cards: only on your devices, your own home server, device to device. There is no central server.
- **Tray and open at login** (computers only, both off by default). With the tray on, closing the window hides it and leaves ScaleNote running so other devices can still sync; open it from the tray icon or quit from its menu.
- **Device list.** Each paired device shows when it last synced and which ScaleNote version it runs, and says if it is older than this one.
- **Add-only inbox for the server.** A folder on the server where a script can drop plain `.md` files; the server moves them into the vault's `Inbox` folder. It never overwrites or deletes a page, and rejects anything else.

## Fixed after review
- The server refused a data folder inside a vault only if that folder already existed; a new one could be made inside a vault, putting the keys where they would sync. It is now checked before it is made.
- `scalenote-server pair` could show an empty code if it read the code file while it was being written. The file is now written in one step, and an empty code is never shown.
- The guide no longer suggests pairing one device with two server vaults, which could mix notes between them.
- On a phone, the Settings window could reach past the bottom of the screen.
- In Auto with the Light and Dark cards, Light looked like True white. Light now always looks like Light.

## Not yet tried
- Tray and open at login were written against the real programming interfaces but could not be built on the machine they were written on; they are only compiled by the build service. Try them on Windows and Linux. The window is not started hidden at sign-in.
- Everything on Android, the server over days, and sync between two real devices.
