This is still an early test version: keep your own backup of anything you care about.

## New
- **Find devices.** When you pair, the other device no longer needs its address typed. Start pairing on one device, then on the other choose "Find devices" in Settings, Sync: devices that are showing a code appear in a list, and "Use" fills in the address. If nothing is found, typing the address still works.
- A device only announces itself while its pairing code is showing, and stops as soon as the code runs out or you close the screen. A device that is just switched on cannot be seen on the network.

## Fixed
- A canvas block no longer says its region could not be found after you open the Split view.

## Changed
- Android: a phone may not be able to find other devices yet (Android needs extra permission for that, planned for a later version). Other devices can still find the phone, and you can type an address on the phone.
