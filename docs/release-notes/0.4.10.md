# ScaleNote 0.4.10

This is still an early test version: keep your own backup of anything you care about.

## New
- Draw on the text. A pen button on the top bar of a page (next to the clock) puts a pen bar above the text and a see-through sheet over it. A pen or a mouse draws on the words; a finger still scrolls the page. The bar has a pen, a highlighter, an eraser, the sixteen colours, five line widths, Undo and Redo, a "Finger draws" switch for a device without a pen, and Done.
- The ink stays on its words. Each stroke belongs to the paragraph, heading, list or other block it was drawn on, so it follows that block when the window gets wider or narrower and the text wraps differently.
- A page with ink shows it over the text whenever you open the page, with no pen bar. A page without ink is opened as before.
- The ink is saved in the same drawing file as the canvas (`Name.canvas.json`). The page text is never changed by drawing. Opening the Canvas view still shows only the canvas and keeps the ink as it is.

- Columns. Type `/2 columns` or `/3 columns`, or drag a block by its handle to the left or right side of another block: a vertical line shows where it will go, and the two blocks become columns. Drag a block to the edge of a set of columns to add a column (up to five), drag blocks between columns, or use the block menu: "Move out of the columns" and "Turn columns into blocks". A column that becomes empty goes away, and a set with one column left turns back into plain blocks. On a narrow screen the columns stack under each other.
- In the file, columns are an Obsidian-style callout holding callouts (`> [!columns]` with `> > [!column]` inside), so Obsidian still opens the page and shows the text. Anything that does not have exactly that shape stays an ordinary callout, byte for byte.
- Install updates inside the Android app. On Android, "Download" in the update notice and in Settings now downloads the new version inside ScaleNote and opens Android's installer, where you confirm. The first time, Android sends you to a settings screen to allow ScaleNote to install apps; allow it and press Download again. Only a file from the ScaleNote releases on GitHub is accepted. If anything fails, the browser download is used as before. Other systems are unchanged.

## Good to know
- If you edit the first words of a block that has ink, the ink no longer finds its block. It is not drawn, but it is not deleted either: it comes back if the words come back, and it stays in the drawing file.
- Ink is kept in a newer file format (format 5). An older ScaleNote opens a drawing with ink read-only instead of saving over it, so it can never lose the ink.
- Ink is not part of printing or exporting a page yet.

## Known limits
- Not tried on a real device yet: pen pressure, a finger scrolling while a pen is held, and a touch screen on Linux. Two-finger zoom on Linux still zooms the whole window.
- Not tried on a real device: the Android in-app installer (it is only built by the automatic build here, never run), and dragging blocks into columns with a finger or pen. Ink inside columns is anchored to the whole columns block, not to a single column.
- Columns do not nest, and a column holds the same kinds of blocks as a callout.
