# ScaleNote 0.2.5

This is still an early test version: keep your own backup of anything you care about.

## New
- **Move pages and folders by dragging.** Drag a page or folder in the list onto a folder to move it in. Drag it onto the empty space below the list to move it to the top level. The folder that will receive it is outlined, and a small label follows the pointer. Escape cancels. Nothing is ever replaced: if the target already has something with that name, the move stops and says so. A folder cannot be moved into itself.
- **Move to** in the right-click menu does the same without dragging, so it also works on a touch screen and with the keyboard.
- **A copy of the block follows the pointer** while you drag a block, and the original stays where it is until you drop.
- **Select several blocks and move them together.** Select text across blocks, then drag the handle, use the handle menu, or press Alt with the up or down arrow. Duplicate and Delete in the menu apply to all of them, and one Undo puts a move back.
- **A plus button** next to the block handle adds an empty block below. On a narrow window, the handle menu has "Add block below" instead.
- **The selection bar starts with the block type.** It shows what the block is (Text, Heading 2, and so on) and opens the list to turn it into something else.

## Fixed
- Pressing Undo right after opening a page used to empty the editor, and the empty page could then be saved over the real one. Opening a page no longer counts as something to undo.

## Not in this release
Dragging pages and folders with a finger (use Move to), dropping a block next to another to make columns, and delete or duplicate for pages and folders.
