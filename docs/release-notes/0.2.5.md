This is still an early test version: keep your own backup of anything you care about.

## New
- **Move by dragging.** Drag a page or folder onto a folder to move it in, or onto the empty space to move it to the top level.
- **Move to** in the right-click menu does the same without dragging.
- **Block drag preview.** A copy of the block follows the pointer while dragging.
- **Several blocks at once.** Select across blocks, then drag, use the handle menu or Alt with the arrow keys.
- **Plus button** next to the block handle adds an empty block below.
- **Block type in the selection bar** to turn a block into something else.

## Fixed
- Undo right after opening a page no longer empties the editor.
