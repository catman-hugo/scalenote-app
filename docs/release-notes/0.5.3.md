This is still an early test version: keep your own backup of anything you care about. This is the first version that really exchanges pages between two of your devices, and it has only been tried on one computer, not on two real devices.

## New
- **Sync between two paired devices on the same network.** Choose "Sync now" next to a paired device in Settings, Sync. Only pages and files that changed are sent. Every change is written safely: a page is never half written.
- **The first sync asks first.** It shows what it would send, receive and skip, changes nothing, and waits for your yes.
- **If a page changed on both devices, both versions are kept.** The newer one keeps the name; the older one is saved next to it as a "conflict" copy on both devices.
- **Deleted pages go to the trash on the other device**, so a deletion can be undone there.
- **Automatic sync.** While the app is open, a device you have already synced with is synced again when it appears on the network, and every few minutes. The first sync with a device is never automatic.
- **Status line.** The bottom of the page list always says where sync stands, for example "Synced · 3 changed".
- **Pause sync.** One button stops this device from starting or answering a sync, and from announcing itself. It stays paused until you resume or close the app.
- **Compare.** Shows what a sync would do without changing anything.
- **Rename a paired device** to a name you recognise.
- **Changes made by another program are noticed.** The page list, favourites and the open page refresh by themselves when files in the folder change.
- **Conflict copies screen.** Look at both versions side by side and keep one; the other goes to the trash.
- **What this app does on the network** is written in plain words in Settings, Sync.
- **Sync activity** lists the latest syncs and any problems.

## Changed
- A paired device now announces itself on the local network while sync is on and not paused (before, only while a pairing code was showing). Other devices can see its name. Pause sync stops that.
- Files bigger than 64 MB are not synced; the sync says which ones.
