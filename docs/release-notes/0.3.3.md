This is still an early test version: keep your own backup of anything you care about.

## New
- **Page links.** `[[Page name]]` becomes a clickable link, readable by Obsidian too.
- **Link list.** Typing `[[` lists pages. `[[Page|text]]`, `[[Page#Heading]]`, `[[Page#^block]]` and `[[#Heading]]` work as well.
- **Missing pages.** A link to a page that does not exist is dashed and creates the page when clicked.
- **Linked from.** A list under every page shows the pages that link to it. It can be switched off in Settings.

## Changed
- Pages with links are edited like any other text and written back exactly as they were.
