# ScaleNote 0.3.3

This is still an early test version: keep your own backup of anything you care about.

## New
- Links between pages. Write `[[Page name]]` in a page and it becomes a link you can click. Obsidian reads the same text the same way, so the links also work there.
- Type `[[` to get a list of your pages. Keep typing to narrow it, press Enter (or tap a row) to write the link. If the page does not exist yet, the last row offers to link to it anyway.
- The usual forms work: `[[Page|text to show]]` shows your own text, `[[Page#Heading]]` jumps to a heading, `[[Page#^block-id]]` jumps to a block (the block links the left handle already writes), and `[[#Heading]]` points inside the same page.
- A link to a page that does not exist is drawn dashed and grey. Clicking it makes the page (at the top of your notes folder, or in the folder the link names if that folder exists) and opens it.
- Under every page there is now a "Linked from" list: the other pages that have a link to this one, with the line each link is on. Click one to open it. The list can be hidden with its Hide button, or switched off in Settings ("Show the Linked from list under pages"); while it is off, your pages are not searched for links at all. It is on by default.

## Changed
- A page that has `[[links]]` used to be shown as one grey "kept exactly as written" box. Now it is edited like any other text. A link is always written back exactly as it was written, so opening and saving a page does not change it.
- Anything that is not a plain link is still kept exactly as written, as before: `![[embedded pages]]`, links inside code, links in table cells, callout titles and toggle titles, and a `[[` that is never closed.

## Known limits
- Renaming or moving a page does not yet change the links that point to it in other pages. They show as dashed until you fix them.
- A link cannot be edited in place: delete it (Backspace removes the whole link) and write it again.
- `[[Page#` does not list headings yet; you can type the heading by hand.
- The "Linked from" list reads your pages each time a page is opened, like search does, so it can be slow in a very large notes folder.
