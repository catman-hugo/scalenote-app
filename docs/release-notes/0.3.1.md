# ScaleNote 0.3.1

A small release about updating on Android. This is still an early test version: keep your own backup of anything you care about.

## Fixed
- Android: the arrow next to the folder name at the top of the page list did nothing, because the notes folder on Android is fixed. It is gone on Android. On Windows and Linux it still opens the folder menu.
- Android: every new build used to be signed with a new key, so Android would not install it over the old one. You had to delete the old app, which also deleted your notes and settings, and you saw the first-run screens again. From this build on, every build is signed with the same key, so a new version installs as a normal update: your pages, settings and choices stay.

## Important: one last reinstall
Builds before 0.3.1 were signed with different keys, so Android will refuse to install 0.3.1 over them. Remove the old app once, then install 0.3.1. Pages in the Android app's private storage are deleted with it, so copy anything you want to keep out first. After that, updates just install over the old version.

## How to update on Android
Open Settings and use Check now, then Download (or download the .apk from the release page), open the file and confirm "Update". Nothing needs to be deleted and nothing is asked again.
