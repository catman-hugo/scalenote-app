# ScaleNote 0.2.6

A small release. This is still an early test version: keep your own backup of anything you care about.

## Fixed
- On an Android phone, tapping into a page no longer slides the whole screen up and out of view. The keyboard now covers the bottom of the page, the title bar stays where it is, and the page only scrolls as far as it needs to so you can see the line you are typing. If the line is already visible, nothing moves.

## Not in this release
This fix needs a real phone to prove it. If the screen still jumps, send a screenshot and the next version will go further.
