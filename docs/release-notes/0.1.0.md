This is still an early test version: keep your own backup of anything you care about.

## New
- **Notes folder.** Open a folder as the notes folder, or let ScaleNote create one.
- **Page list.** Folders and notes in a list on the left. Folders open and close.
- **Editor.** Headings, bold, italic, lists, to-do lists, quotes, code and dividers. Type `/` to pick a block.
- **Autosave.** Notes save a moment after typing stops and when leaving the note.
- **Rename** a note by editing its title.
- **Plain markdown files**, so Obsidian opens the same folder.
- Syntax the editor cannot edit yet (tables, html, wikilinks, callouts, images, math) is kept exactly as written.
- Builds for Windows, Linux and Android.
