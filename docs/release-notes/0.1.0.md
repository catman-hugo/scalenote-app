# ScaleNote 0.1.0

The first version you can write notes in. It is an early test version: expect bugs, and keep your own backup of anything you care about.

## What you can do
- Open a folder as your notes folder, or let ScaleNote create one (Documents/ScaleNote on a computer, private app storage on Android).
- See folders and notes in a list on the left. Folders open and close. On a narrow screen the list slides over the note.
- Write notes with headings, bold, italic, lists, to-do lists, quotes, code and dividers. Type `/` to pick a block.
- Notes save by themselves a moment after you stop typing, and when you leave the note or close the window.
- Rename a note by editing its title at the top.
- Open the same folder in Obsidian: notes are plain markdown files.

## Good to know
- A note you only open is never rewritten.
- Things ScaleNote cannot edit yet (tables, html, wikilinks, callouts, images, math) are shown in a dashed box labelled "Kept exactly as written". You can edit them as plain text, and they are saved exactly.
- The first time you save a changed note, an `id:` line is added to its frontmatter.
- If another program changes a note while you have it open, the version on disk is loaded and what you typed is saved as "<name> (conflict copy)".
- There is no delete, move or search yet.
- The pen test page from the earlier test version is still available from the bottom of the list.

## Downloads
Windows installer (.msi and .exe), Windows portable zip, Linux (.deb, .rpm, .AppImage) and an Android test APK.

## Not tested on real devices yet
