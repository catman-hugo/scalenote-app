Two fixes for syncing between your own devices, found while testing 0.6.6.

## Fixed
- **Pen writing over the text now arrives on your other devices without reopening the page.** A sync that only brought new writing (the page text was the same) did not show it until the page was opened again. Writing erased on another device also goes away here.
- **Pen writing next to a PDF in a page stays put.** It was tied to the words the PDF happened to show at that moment, so another device, or the same one after scrolling the PDF, did not find it and did not draw it. It is now tied to the PDF file (and next to a canvas region, to that region). Writing made before this fix is found again in the same place.
- **Folders sync, not only the pages in them.** A new empty folder now reaches your other devices, and a folder you move or delete no longer stays behind, empty, on the other device. A folder is only ever removed when it is empty there: if something was added to it on the other device in the meantime, it stays. Both devices need this version; with an older one, folders work as before.

## Good to know
- Empty folders left behind by an earlier version (after you moved a folder on another device) cannot be told apart from new ones. The first sync with this version may copy such an empty folder to your other devices. Delete it once on any device and it goes away everywhere, or delete these empty folders before the first sync.
