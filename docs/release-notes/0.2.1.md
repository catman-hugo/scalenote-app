# ScaleNote 0.2.1

A small polish release. Nothing new to learn, a few things are easier to see and use. This is still an early test version: keep your own backup of anything you care about.

## Changed
- The first-run screen now says where the default folder is, under the buttons.
- Settings now has a gear icon, so it is easy to find. All icons now follow the theme, and no emoji or typed symbols are used in the screens.
- "Open another folder" is now at the top of the note list.
- The note list no longer gets squished when it is made narrow. Buttons stay on one line, and show only their icon when there is not enough room.
- The "What's new" box is wider and taller.
- The block handle now lines up with the first line of its block, also for dividers, code, callouts and toggles.
- While you drag a block, the handle you grabbed is hidden.
