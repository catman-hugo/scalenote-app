## Changed
- The first-run screen shows where the default folder is.
- Settings has a gear icon. All icons follow the theme.
- "Open another folder" is at the top of the page list.
- The page list keeps its buttons on one line when narrow and shows only icons if needed.
- The What's new box is wider and taller.
- The block handle lines up with the first line of its block, also for dividers, code, callouts and toggles.
- The handle that is being dragged is hidden.
