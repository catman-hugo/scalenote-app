# ScaleNote 0.3.8

This is still an early test version: keep your own backup of anything you care about.

## Changed
- The History box is tidier, after the first test on a tablet. The "Put back" buttons only show once you have chosen a version, a page with only one older version opens that version straight away, and the properties block at the top of a page is shown as one folded line ("Page properties") instead of separate lines.
- If keeping an older version of a page fails (for example because the folder cannot be written), the save still works, and the problem is now written to the log file so it can be found.

## Known limits
- The History box does not yet tell you when older versions cannot be kept; only the log does.
- Everything else is as in 0.3.7.
