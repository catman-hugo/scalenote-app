This is still an early test version: keep your own backup of anything you care about.

## New
- **Selection bar.** Bold, italic, strikethrough, code and link on selected text. Ctrl+K starts a link.
- **Callouts, toggles and tables** as real editable blocks.
- **Pictures.** Insert, paste or drop PNG, JPG, GIF and WebP (up to 10 MB). They are kept in an `attachments` folder.
- **Block handle.** Move, duplicate, delete, turn into another block type and copy a block link. Drag to move.
- **Markdown view.** A Markdown button switches a page to plain markdown and back.
- **Themes.** Eight colour themes plus follow the system. Settings for text size, page width and list width.
- **Update check.** A notice with Download and What's new buttons when a new version exists. One switch in Settings turns it off.
