# ScaleNote 0.2.0

The editor is now much more complete. This is still an early test version: keep your own backup of anything you care about.

## New
- Select some text and a small bar appears with bold, italic, strikethrough, code and link. Ctrl+K (or Cmd+K) also starts a link. Only web and email addresses can be links.
- Callouts, toggles (fold-away blocks) and tables are now real blocks you can edit. Type `/` to add one. A note that already has them is not changed just because you opened it.
- Pictures: choose Image from the `/` menu, paste a picture, or drop one into the note. The picture is copied into an `attachments` folder inside your notes folder, and the note holds a normal markdown picture line. PNG, JPG, GIF and WebP up to 10 MB are accepted. SVG files are refused on purpose.
- Every block has a handle (two dots) on its left. Click or tap it for a menu: move up, move down, duplicate, delete, turn into another block type, copy a link to the block. Press and drag the handle to move a block with a mouse, finger or pen. Alt+Up and Alt+Down also move the block you are in.
- A Markdown button at the top switches the whole note to plain markdown text and back. What you type there is saved exactly as it is.
- Eight colour themes: light, dark, sepia, midnight, sage, forest, lavender and dusk, plus "follow the system". There is a Settings button at the bottom of the note list for the theme, text size, note width and list width.
- ScaleNote looks for new versions. When one exists, a notice appears with a download button and a "What's new" button. After an update, the new notes are shown once.

## Update check
- It is on by default. It only reads the public list of releases on GitHub, at most twice a day. It sends nothing from your notes. GitHub can see your internet address, like any website.
- One switch in Settings turns it off.
- Installing updates by itself is not possible yet, because the installers are not signed yet. For now the notice opens the download page.

## Good to know
- A block link looks like `[[Note title#^abc123]]`. Copying it adds a small ` ^abc123` marker to the block (Obsidian uses the same marker). Following these links is planned for a later version.
- Underline, highlight, colour, subscript and superscript are not in this version.
- The phone keyboard no longer pushes the top bar under the status bar (to be confirmed on the phone).
- Pictures that are missing from the `attachments` folder show a short message and the note is left alone.

## Not tested on real devices yet
Everything here was tried in a test browser and by automatic checks only. Please try on a real device: choosing and pasting pictures (especially on Android), dragging blocks with a finger and a pen, the phone keyboard layout, the download button in the update notice, and the themes on the real screens.
