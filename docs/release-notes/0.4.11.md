# ScaleNote 0.4.11

This is still an early test version: keep your own backup of anything you care about.

## Fixed
- The Android file of 0.4.10 could not be installed ("There was a problem while parsing the package"). It declared the same file provider twice. Android now accepts it, and the build checks the finished file for this.
- A pen that starts in the margin left of or above the text now draws. Before, it scrolled the page instead.
- A long stroke across a page (a big scribble) could make the saved drawing unreadable the next time the page was opened. A stroke is now saved in one piece per block it crosses, so the drawing always opens.
- Ink drawn in the empty space below the last line of a page was flattened into a horizontal line and moved up when you left the page and came back. It now keeps its shape.
- The logo is moved a little so it sits in the middle of the round icon on the phone, in the launcher and the app list.

## Changed
- The pen bar has no Done button. The pen button on the top bar starts and stops drawing.
- A long stroke that crosses several blocks is saved as several pieces, so the eraser removes it piece by piece. Undo still removes the whole stroke in one step.

## Good to know
- Not tried on a real device: installing the Android file, drawing in the margin with a pen on a touch screen.
- The Android in-app installer from 0.4.10 is still not tried on a device.
