This is still an early test version: keep your own backup of anything you care about.

## Changed
- The pen bar has no Done button. The pen button on the top bar starts and stops drawing.
- A long stroke across several blocks is saved as several pieces, so the eraser removes it piece by piece.

## Fixed
- The Android file of 0.4.10 installs again.
- A pen that starts in the margin next to the text draws.
- A long stroke across a page no longer makes the saved drawing unreadable.
- Ink drawn below the last line keeps its shape.
- The logo sits in the middle of the round icon.
