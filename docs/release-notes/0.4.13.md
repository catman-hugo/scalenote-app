This is still an early test version: keep your own backup of anything you care about.

## New
- **Page colours.** Pages can have a colour, with the same sixteen colours as folders.
- **Region names.** Canvas regions can be named. The name shows on the canvas and above the block in the text.
- **Download progress.** On Android, a bar shows how far an update has downloaded.
- **What's new setting.** Settings can switch the What's new box off.

## Changed
- The app icon is now centred.
- The What's new box fits small screens and shows its notes as bullet points.
