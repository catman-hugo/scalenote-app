# ScaleNote 0.4.8

This is still an early test version: keep your own backup of anything you care about.

## New
- Renaming a page now updates the links to it. Rename a page in the page list or from its title, and every `[[link]]` to it in your other pages (and in the page itself) points to the new name. Only the name inside the link changes: a heading or shown text after it stays as you wrote it. If a page cannot be updated, you are told, and the rename stays.
- The Tags box can fold. Press a main tag such as #school to show or hide the tags inside it, like #school/maths. Main tags start folded, and typing in the filter lists every match.
- Toggles keep their outline whether they are folded, open, or not in use, so you can always see where one starts and ends.
- A page with toggles opens with all of them folded the first time you open it after starting the app. After that it stays as you left it until you close the app. Folding is never written into your page.
- The History box shows an older version the way the page looks (headings, lists, bold, tables, toggles) when you open it from the normal text. Opened from the Markdown view it shows the markdown, as before. Changes are compared block by block there, so a changed list or table is shown, and put back, as a whole.
- The View menu (Text, Canvas, Split) replaces the separate Canvas and Split buttons in the top bar, so the bar fits on one row on a phone. (This was built after 0.4.7 and is part of this release.)

## Changed
- Empty lines are kept. Press Enter on an empty line a few times, open another page and come back: the empty lines are still there. In the file they are extra blank lines, so the page stays plain markdown.
- Fixed: on Linux, all text turned bold once a page was long enough to scroll. The scrolling boxes now have a solid background. I could not try this on Linux myself, so please check it there.

## Known limits
- Empty lines are kept at the top level of a page, not inside a toggle or a callout.
- Renaming or moving a folder does not rewrite links that are written with the folder in them.
- Not yet tried on a real device: the bold-text fix on Linux, the History view, the folding of toggles and tags.
- Two-finger zoom on Linux still zooms the whole window instead of the drawing. It is known and not fixed in this version.
- Drawing over text, columns and the Android in-app installer are planned for 0.4.9.
