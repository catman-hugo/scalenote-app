This is still an early test version: keep your own backup of anything you care about.

## New
- **Find in page.** Ctrl+F finds a word in all the text of a page and in the PDFs shown in it, counts the matches, marks them and jumps from one to the next in page order.
- **PDF text.** In a PDF block you can select and copy text.
- **Drawings in print.** Printing or saving as PDF now includes the drawing over the text, and canvas blocks print black on white in any theme.
- **Drawings in export.** Exporting a page as markdown adds the page's drawing as a picture at the end of the page.

## Changed
- Drawing over the text is only in print and PDF, not in the markdown export, because markdown has no place for ink over words.
