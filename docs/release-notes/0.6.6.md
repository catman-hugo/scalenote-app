This is still an early test version: keep your own backup of anything you care about.

## New
- **Share things into ScaleNote on Android.** ScaleNote is in Android's share menu for text, links, pictures, PDFs and markdown files, one or several at once. Long-press the ScaleNote icon for **New page**; you can drag it to the home screen.
- **Send to and Open with on Windows.** Right-click a file and choose **Send to, ScaleNote**, or **Open with, ScaleNote** for pictures, PDFs and markdown files. ScaleNote is only added to the list: it does not become the default program for anything.
- **Open with on Linux.** ScaleNote is listed under Open with for pictures, PDFs and markdown files, and you can drop files on the page list.
- **One box for everything that comes in.** It shows what arrived and asks where it goes: a new page in your inbox folder, or the end of the page you have open. Links become links, pictures and PDFs show in the page, and markdown files become text. Anything else is not added, and the box says so.
- **New page from clipboard**, in the search box (Ctrl K) on every device. If the clipboard cannot be read, a box asks you to paste.
- **New page from anywhere on a computer**: the tray menu has **New page**, and Settings, Files has the **Ctrl+Alt+N** shortcut. Both are off until you turn them on, like the tray.
- **Settings, Files: Shared things go to** chooses the inbox folder (Inbox unless you pick another). It is made when it is missing.

## Fixed
- **Pen writing over the text now arrives on your other devices without reopening the page.** A sync that only brought new writing (the page text was the same) did not show it until the page was opened again. Writing erased on another device also goes away here.
- **Folders sync, not only the pages in them.** A new empty folder now reaches your other devices, and a folder you move or delete no longer stays behind, empty, on the other device. A folder is only ever removed when it is empty there: if something was added to it on the other device in the meantime, it stays. Both devices need this version; with an older one, folders work as before.
- **Pen writing next to a PDF in a page stays put.** It was tied to the words the PDF happened to show at that moment, so another device, or the same one after scrolling the PDF, did not find it and did not draw it. It is now tied to the PDF file (and next to a canvas region, to that region). Writing made before this fix is found again in the same place.

## Good to know
- Folders left behind empty by an earlier version (after you moved a folder on another device) are not known to be old. The first sync with this version may copy such an empty folder to your other devices. Delete it once on any device and it goes away everywhere. Or delete these empty folders before the first sync.
- Opening a file with ScaleNote while it is already running hands the file to the open window; a second copy of ScaleNote is never started.
- Some Linux desktops (Wayland) do not allow shortcuts like Ctrl+Alt+N; Settings says so when that happens.
