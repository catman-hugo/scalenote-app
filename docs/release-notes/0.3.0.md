# ScaleNote 0.3.0

This is still an early test version: keep your own backup of anything you care about.

## New
- Search. Press Ctrl+K (or use the Search button at the top of the page list, which is the way to do it on a phone) and type. ScaleNote looks in the titles and the text of all your pages and shows the best matches first: a page whose title is exactly what you typed, then pages with it in the title, then pages with it in the text. The matching line is shown under each result. Every word you type has to appear in the page. Up and Down choose, Enter opens the page, Escape closes the box.
- The same box runs commands. With nothing typed it lists the pages you opened in this session and the commands; type a few letters of a command to find it: New page, New folder, Open settings, Open trash, Show or hide the page list, and Show or hide the markdown text of this page.
- Delete. The right-click or long-press menu of a page or folder now has Delete, and the Delete key does the same on a page or folder in the list. Nothing is destroyed: it goes to the trash. If the page you had open is deleted, it closes. Whatever you typed last is in the trash copy.
- Trash. The Trash button at the bottom of the page list shows what you deleted, newest first, with where it came from. Restore puts it back where it was (at the top level if that folder is gone, and with "(restored)" added to its name if the name is taken; nothing is ever replaced). Delete forever and Empty trash ask again before they remove anything.

## Notes
- The trash is a hidden folder called `.trash` inside your notes folder, so Obsidian also treats it as its own trash and ignores it. Search and the Obsidian copy skip it. Nothing is emptied automatically.
- Pictures that belonged to a deleted page stay in the pictures folder.
- Search reads your pages again on every search, so it is always up to date but gets slower in a very large notes folder (3,000 test pages take well under a second). A search that hits its limits says so.
- Search does not yet jump to the match inside the page, and does not search file names of pictures.
- Also fixed: pressing Enter on a button in Settings (or the other boxes) no longer closes the box by mistake, and a page name ending in an accented letter could break the page list.
