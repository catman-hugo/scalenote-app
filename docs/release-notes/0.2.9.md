# ScaleNote 0.2.9

This is still an early test version: keep your own backup of anything you care about.

## New
- Text styles inside a line: highlight, underline, subscript, superscript and text colour. Select some text and use the buttons on the bar that appears. Underline is also Ctrl+U, highlight Ctrl+Shift+H, subscript Ctrl+comma and superscript Ctrl+period.
- Eight text colours, picked to stay readable on every theme. "No colour" takes the colour off again.
- The styles are saved in the page itself, in a form other programs understand: highlight as `==text==`, the others as small html tags. Obsidian shows highlights; for the html tags see the notes below.

## Fixed
- Android: the bar with the formatting buttons now appears when you select text with your finger, like on the computer. Android's own Cut and Copy menu still appears too, and the bar sits a little lower so the two do not cover each other.

## Notes
- A line that uses html or colours from another program that ScaleNote does not know stays as it was and is shown as a plain code block, so nothing is lost or changed.
- Obsidian does not apply bold or italic inside an html tag. If you mix them, Obsidian may show the stars instead of the formatting. ScaleNote itself shows them correctly.
- On a narrow phone the bar wraps to two rows.
