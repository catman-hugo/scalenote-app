This is still an early test version: keep your own backup of anything you care about.

## New
- **PDF pages are added in the background.** Adding a PDF as pictures now shows a small progress card with the pages done and the time left. You can keep writing or open other pages while it runs, and the pictures arrive in the page you started from. Stop is on the card, and only one PDF is added at a time.
- **Sync tab in Settings.** It has a switch for sync (on by default) and a name for this device. Your choices are saved on this device only, never inside your notes folder.
- **Pair two of your devices.** In Settings, Sync, "Pair a device" shows an 8-digit code and this device's network address for two minutes. On the other device you type the address and the code under "Enter a code from another device". After that the two devices trust each other. A wrong code, an old code or a copied code is turned away, and the code stops working after three wrong tries.
- **Paired devices list.** Shows each paired device with a short fingerprint you can compare on both screens, and a Remove button (two clicks, so it cannot happen by accident).
- **Sync activity list.** Shows when a device was paired, turned away or removed.
- **Safe keys.** Each device makes its own secret key. On Windows it is kept in the system's secure storage. On Linux and Android it is kept in a private file in the app's own folder for now (not in your notes folder).

## Changed
- Adding a PDF as pictures is a little faster. The pictures themselves are exactly as before.
- Pairing only connects your devices. No pages are exchanged yet; that comes in a later version.
- This device only listens on the network while a device is paired or the pairing screen is open.
