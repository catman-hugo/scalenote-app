# ScaleNote 0.2.3

A small fix release. This is still an early test version: keep your own backup of anything you care about.

## Fixed
- "Check now" and the automatic check now also find new versions that GitHub labels "Pre-release". Until version 1.0 every release is a test build with that label, so before this the check always said you had the latest version.

## Note
Versions older than 0.2.3 cannot see pre-release builds. If you are on 0.2.2 or older, install 0.2.3 by hand once. From then on the app finds new versions itself.
