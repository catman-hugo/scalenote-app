This is still an early test version: keep your own backup of anything you care about.

## Changed
- **Sticky notes** are drawn by dragging out the box and can be resized with the loop tool.
- **Shapes snap to a grid** so shapes drawn at different times line up. Can be switched off in Settings.
- **Pen colours** are the sixteen colours of OneNote.

## Fixed
- Two-finger zoom keeps the spot between the fingers in place.
- A page with an id but no text opens as an empty page.
