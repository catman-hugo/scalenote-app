# ScaleNote 0.4.12

This is still an early test version: keep your own backup of anything you care about.

## New
- **PDF import.** Type `/pdf` or drop a PDF on a page, then choose how to add it:
  - *Scroll through*: the PDF is kept in the vault's `attachments` folder and shown in the page, where you can scroll through it.
  - *Pages as images*: every page becomes a picture (up to 100 pages) with an empty line after it, so you can draw and type next to each page.
  A PDF can be up to 25 MB.
- **Canvas regions.** Type `/canvas` to mark a region of the page's canvas and show it in the text. The block in the text is only a window onto that part of the canvas. All drawing happens in the Canvas view. There you can select a region by its dashed border with the Loop tool, move it, resize it by its corners and delete it. Each change is one Undo step.
- **Picture handles.** Click a picture to resize it with eight handles (corners keep the proportions, edges stretch one side). Handles work with a mouse, a finger and the arrow keys. An "Original size" button puts it back. The size is saved in the markdown as `![alt|300x200](path)`.

## Fixed
- Going from the Canvas view back to the text now shows the saved drawing and the canvas blocks straight away.

## Changed
- Older versions open a drawing that has canvas regions read-only, so nothing in it is lost.

## Good to know
- Not tried on a real device: PDF import on Windows and Android (including a large PDF on a phone), dragging and resizing a region with a finger or pen, and dragging picture handles on a touch screen. The Android, Windows and Linux files were built by the automatic build, but nobody has run them yet.
- Scanned PDFs may take a while to show. Text in some Chinese, Japanese or Korean PDFs may be missing.
- The Canvas view fits the drawing, not the regions, so a region far away from the drawing can start off screen: zoom out to find it. Regions cannot be named yet.
- Drawing inside the canvas block (briefly in the code) was removed: the block is a window only.
- The Android in-app installer from 0.4.10 is still not tried on a device.
