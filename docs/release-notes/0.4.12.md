This is still an early test version: keep your own backup of anything you care about.

## New
- **PDF import.** Type `/pdf` or drop a PDF on a page, then choose how to add it:
  - *Scroll through*: the PDF is embedded in the page
  - *Pages as images*: every page becomes a picture (up to 100 pages)
  - A PDF can be up to 25 MB
- **Canvas regions.** Type `/canvas` to mark a region of the page's canvas and show it in the text.
- **Picture handles.** Click a picture to resize it with eight handles.

## Fixed
- Going from the Canvas view back to the text now shows the saved drawing and the canvas blocks straight away.
