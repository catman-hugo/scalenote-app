# ScaleNote 0.3.6

This is still an early test version: keep your own backup of anything you care about.

## New
- Tags. Write `#name` in a page and it is marked as a tag. Click a tag to open the Tags box on it. Obsidian reads the same text the same way, so your tags also work there. Tags in the properties at the top of a page (`tags: [a, b]`) are listed too.
- A tag is letters, digits, `_`, `-` and `/`, written after a space or at the start of a line. A number on its own (`#1984`) is not a tag. A tag with a slash is a nested tag: `#school/maths` is listed under `#school` as well. `#Plan` and `#plan` are the same tag.
- The Tags box shows every tag with the number of pages. Pick a tag to see its pages, and click a page to open it. There is a filter at the top. Open it with "Tags" at the bottom of the page list, or "Open tags" in the search box (Ctrl+K).
- Favorites. The star next to a page's title marks the page as a favorite. Favorite pages are listed above the page list; the list is not shown while there are none. The star is also in the search box ("Add or remove this page from favorites"). A favorite is stored as `favorite: true` in the page's properties, which Obsidian shows as a checkbox.

## Changed
- A page with `#tags` used to be shown as a grey "kept exactly as written" box. Now it is edited like any other text. A tag is written back exactly as it was written, so opening and saving a page does not change it.
- A `#word` that is not a tag by these rules (a number such as `#1984`, say) still keeps its paragraph as written, as before.
- The row at the bottom of the page list (Settings, Tags, Trash) goes onto a second line when it is narrow, instead of cutting a word short.

## Known limits
- There is no list of suggestions while you type `#` yet, and you cannot rename or merge tags.
- The `tags:` property cannot be edited from the interface; use the markdown text view.
- The star only works for the page that is open, and is switched off in the markdown text view.
- The Favorites list and the Tags box read your pages from the files, as search does, so reading is slower in a very large notes folder. A favorite changed by another program shows after the next refresh of the page list.
- If a `favorite` entry in the properties is written over several lines (a list, for example), ScaleNote does not change it and says so.
