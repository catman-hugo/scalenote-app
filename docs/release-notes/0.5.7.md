This is still an early test version: keep your own backup of anything you care about.

## New
- Computers: **First update from inside the app.** If you pressed Update in 0.5.6, ScaleNote downloaded this version in the same kind of file you installed, checked that it comes from ScaleNote's own builds, installed it and restarted by itself.
- **Sync over Tailscale**, for networks such as eduroam where devices cannot see each other. With Tailscale on, Settings, Sync shows this device's Tailscale address, and the pairing code shows it too, so you can pair from anywhere. Devices that synced once tell each other their Tailscale address, and when a device cannot be found on the network, ScaleNote reaches it there by itself.
- **Copy the app's log** (Settings, About). Copies what ScaleNote noted down recently, such as times and errors, so you can paste it in a message when something goes wrong. It holds no page text, but page and file names can be in it.

## Fixed
- Android: **Adding a PDF as pictures is much faster on a phone.** Turning each page into a picture took about 5 seconds a page on a phone and a fortieth of a second on a computer. It now makes each picture straight away.
- **Sync is quicker.** With sync on, a change reaches your other device in about 10 to 15 seconds without pressing Sync now. It looked every 20 seconds before, so it often took more than half a minute.
- **Pen writing over text keeps its shape** on a wider or narrower screen. Handwriting from a tablet was stretched sideways and squashed on a computer, because the same paragraph is wider and has fewer lines there. It now keeps its size and shape next to the text. Writing made before this version is shown as before.
