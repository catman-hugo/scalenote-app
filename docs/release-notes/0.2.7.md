# ScaleNote 0.2.7

A small release. This is still an early test version: keep your own backup of anything you care about.

## New
- **Check now** in Settings now shows a **Download** button as soon as it finds a newer version. Tap it and your browser downloads the right file for your device: the .apk on an Android phone, the .msi on Windows. Open the file when it is done to install the update. Your pages are not touched.
- Next to it is **Open the release page**, which opens the new release on GitHub.
- The "new version" bar at the top has the same button.

## Changed
- On Linux there is no single right file (.deb, .rpm or AppImage), so the button opens the release page, where you pick yours.
- The Settings switch is now called "Look for new versions". It never installed anything by itself, so the old name was wrong.

## Not in this release
Installing without opening the file yourself. That needs signed installers, which come later.
